## Setup

```go
import "github.com/xraph/nexus/audit_hook"

recorder := audit_hook.RecorderFunc(func(ctx context.Context, event *audit_hook.AuditEvent) error {
    log.Printf("audit: %s %s %s", event.Action, event.Resource, event.ResourceID)
    return nil
})

gw := nexus.New(
    nexus.WithExtension(audit_hook.New(recorder)),
)
```

`audit_hook.New(recorder, opts...)` takes any `audit_hook.Recorder` (a single `Record(ctx, *AuditEvent) error` method, the same shape as chronicle's emitter). Each call gets its own `*AuditEvent`, so a recorder may keep or modify it. `audit_hook.WithLogger(l)` gives it a go-utils logger for recorder errors.

## Audit Events

Each event contains:

```go
type AuditEvent struct {
    Timestamp  time.Time
    Action     Action
    Resource   Resource
    Category   Category
    ActorID    string // never set by audit_hook today
    TenantID   string // set by the request, tenant, key and budget hooks
    ResourceID string
    Details    map[string]any
}
```

IDs such as the tenant or key go in `ResourceID`, and anything else the hook knows (model, provider, tenant) goes in `Details`.

## Actions

The package defines 18 actions in 5 categories:

| Category | Actions |
|----------|---------|
| `request` | `request.received`, `request.completed`, `request.failed`, `request.cached`, `stream.started`, `stream.completed`, `stream.failed` |
| `provider` | `provider.failed`, `circuit.opened`, `fallback.triggered` |
| `security` | `guardrail.blocked`, `guardrail.redacted` |
| `tenant` | `tenant.created`, `tenant.disabled`, `key.created`, `key.revoked` |
| `budget` | `budget.warning`, `budget.exceeded` |

Only the actions whose hooks the gateway fires show up today: the tenant and key actions, the two budget actions and the three stream actions. The request, provider and guardrail actions are defined, but their hooks don't fire yet. See [Plugins](/docs/infrastructure/plugins#lifecycle-hooks).

## Filtering

Record only specific actions:

```go
audit_hook.New(recorder,
    audit_hook.WithActions(
        audit_hook.ActionKeyRevoked,
        audit_hook.ActionBudgetExceeded,
    ),
)
```

## Sending events to Chronicle

Nothing wires `audit_hook` to Chronicle for you, in Forge or out of it. Write a `RecorderFunc` that maps each `*AuditEvent` onto a Chronicle call and pass it to `audit_hook.New`:

```go
recorder := audit_hook.RecorderFunc(func(ctx context.Context, ev *audit_hook.AuditEvent) error {
    return chronicle.Info(ctx, string(ev.Action), string(ev.Resource), ev.ResourceID).
        Category(string(ev.Category)).
        TenantID(ev.TenantID).
        Meta(ev.Details).
        Record()
})
```

`TenantID` is empty for events the gateway can't tie to a tenant, such as provider and stream events. In a Forge app, add the extension with `nexusext.WithGatewayOption(nexus.WithExtension(audit_hook.New(recorder)))`.
