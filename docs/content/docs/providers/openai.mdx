The OpenAI provider talks to OpenAI's Chat Completions and Embeddings APIs: chat, streaming, embeddings, vision and tool calling. Most of the OpenAI-compatible providers (Groq, Together, Fireworks and others) wrap it, so what this page says about requests applies to them too.

## Installation

```go
import "github.com/xraph/nexus/providers/openai"
```

## Quick start

```go
gw := nexus.New(
    nexus.WithProvider(openai.New(os.Getenv("OPENAI_API_KEY"))),
)
```

## Options

| Option | What it does |
|--------|--------------|
| `openai.WithBaseURL(url)` | Sends requests to another base URL (default `https://api.openai.com/v1`) |
| `openai.WithOrgID(id)` | Sets the `OpenAI-Organization` header. It's left off requests that carry a tenant key |
| `openai.WithTimeout(d)` | How long a request waits for response headers. Default 10 minutes |
| `openai.WithMaxCompletionTokens(on)` | Sends `max_completion_tokens` on a base URL other than OpenAI's own |

## max_tokens and max_completion_tokens

On OpenAI's own endpoint, `https://api.openai.com/v1`, the provider sends `CompletionRequest.MaxTokens` as `max_completion_tokens`, which current models require. That includes a request whose [tenant credential](/docs/core/credentials) points at that URL. Any other base URL gets `max_tokens`, which most OpenAI-compatible servers expect. If yours wants the newer field, turn it on:

```go
openai.New(key,
    openai.WithBaseURL("https://llm.internal/v1"),
    openai.WithMaxCompletionTokens(true),
)
```

Reasoning models (the GPT-6 and GPT-5.6 families, `gpt-5.5`, `gpt-5`, `gpt-5-mini`, `gpt-5-nano` and `o3`) reject `temperature` and `top_p`, so the provider leaves them off for those models, on any base URL.

## Tool choice

`CompletionRequest.ToolChoice` is sent in OpenAI's shape whatever shape you used: OpenAI's own (`"auto"`, `"none"`, `"required"`, `{"type":"function","function":{"name":...}}`), Anthropic's (`"any"`, `{"type":"any"}`, `{"type":"tool","name":...}`) or the typed `provider.ToolChoice`. `"any"` goes out as `"required"`. A value the provider cannot read fails before anything is sent, with an error that wraps `provider.ErrNotSupported`; the gateway refuses it with 400 `invalid_request` and does not retry it. Every provider built on this one (opencompat, groq, openrouter and the rest) and `azureopenai` do the same.

`ThinkingConfig.Effort` is not sent to OpenAI: the provider has no `reasoning_effort` mapping, so the field is ignored here.

## Embedding dimensions

`EmbeddingRequest.Dimensions` asks for a vector width. Zero keeps the model's default.

```go
resp, err := gw.Engine().Embed(ctx, &provider.EmbeddingRequest{
    Provider:   "openai",
    Model:      "text-embedding-3-small",
    Input:      []string{"hello"},
    Dimensions: 512,
})
```

On OpenAI's own endpoint only the `text-embedding-3` models take a width. The gateway refuses any other model before calling OpenAI, with `middlewares.ErrDimensionsUnsupported` (400 `invalid_request`, wrapping `provider.ErrNotSupported`). On another base URL the provider passes the width through and lets the server decide. Either way the gateway checks what comes back, and a vector of a different length fails the call with an error that matches `middlewares.ErrDimensionsMismatch`.

The provider decides by its configured base URL. A tenant credential that points an `openai` provider somewhere else is still held to OpenAI's rule, so use [opencompat](/docs/providers/opencompat) for tenants that bring their own server.

## Timeouts

`WithTimeout` bounds the wait for response headers, 10 minutes by default. A stream is not cut by it once headers arrive, so bound a whole call with the request context. A non-streamed call through the gateway is also bounded by `nexus.WithTimeout` (30 seconds by default).

## Per-tenant keys

The provider applies a per-request credential, key and base URL. A tenant key drops the configured `OpenAI-Organization` header, and a credential with a `BaseURL` never gets the configured key: with no key of its own, the request goes out with no `Authorization` header. See [Tenant Credentials](/docs/core/credentials).
