Nexus has 30 released provider modules, and you can register as many as you like on one gateway. Each one implements the same interface for chat completions, streaming, embeddings and model listing.

## Provider Interface

Every provider implements `provider.Provider`:

```go
type Provider interface {
    Name() string
    Capabilities() Capabilities
    Models(ctx context.Context) ([]Model, error)
    Complete(ctx context.Context, req *CompletionRequest) (*CompletionResponse, error)
    CompleteStream(ctx context.Context, req *CompletionRequest) (Stream, error)
    Embed(ctx context.Context, req *EmbeddingRequest) (*EmbeddingResponse, error)
    Healthy(ctx context.Context) bool
}
```

`Models` returns a built-in catalog for each provider (IDs, context window, max output and list prices). The gateway prices usage from it and routes a request to the provider that lists its model. It isn't a live list from the provider's API. A model that isn't in any catalog still gets sent through, and it records an unknown cost unless you price it with [`WithPriceOverrides`](/docs/core/pricing#overriding-prices) or refuse it with an [unpriced policy](/docs/core/pricing#models-with-no-price). The `bedrock` catalog is out of date in this release, see [Amazon Bedrock](/docs/providers/bedrock#models).

## Quick Example

```go
import (
    "github.com/xraph/nexus/providers/openai"
    "github.com/xraph/nexus/providers/anthropic"
    "github.com/xraph/nexus/providers/groq"
)

gw := nexus.New(
    nexus.WithProvider(openai.New(os.Getenv("OPENAI_API_KEY"))),
    nexus.WithProvider(anthropic.New(os.Getenv("ANTHROPIC_API_KEY"))),
    nexus.WithProvider(groq.New(os.Getenv("GROQ_API_KEY"))),
)
```

## Capabilities

Each provider reports what it supports through `provider.Capabilities`:

```go
caps := p.Capabilities()
caps.Chat       // chat completions
caps.Streaming  // streamed completions
caps.Embeddings // embeddings
caps.Vision     // image inputs
caps.Tools      // tool/function calling
caps.Thinking   // extended thinking or reasoning
caps.JSON       // structured JSON output
```

The struct also carries `Images`, `Audio`, `Batch` and streaming-specific flags (`StreamingReasoning`, `StreamingTools`, `StreamingAudio`, `StreamingCitations`, `RealtimeAudio`). An embedding request can only go to a provider whose `Embeddings` flag is set. See [Routing](/docs/core/routing#embeddings).

## Provider Health

`provider.NewHealthTracker()` keeps success and failure counts, average latency and P99 latency per provider, and you can hand one to the gateway:

```go
nexus.WithHealthTracker(provider.NewHealthTracker())
```

Nothing reads it yet. The gateway stores the tracker, but routing treats every provider as healthy and doesn't record calls into it, so this option has no effect on which provider answers today.
