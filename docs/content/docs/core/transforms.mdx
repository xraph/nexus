---
title: Transforms
description: Modify requests and responses with system prompts, RAG context, anonymization and output normalization.
---

Transforms change a request before it reaches the provider (input transforms) or a response before it reaches the client (output transforms). You put them in a `transform.Registry` and hand that to the gateway. The transform stage runs at priority 200, after guardrails.

```go
import "github.com/xraph/nexus/transform"

registry := transform.NewRegistry()
registry.Register(transform.NewSystemPrompt("You are a helpful assistant for Acme Corp."))
registry.Register(transform.NewNormalizer())

gw := nexus.New(
    nexus.WithProvider(openai.New(os.Getenv("OPENAI_API_KEY"))),
    nexus.WithTransforms(registry),
)
```

## Transform Interfaces

Every transform has a name and a phase. What it does depends on which of these it implements:

```go
type Transform interface {
    Name() string
    Phase() Phase // transform.PhaseInput or transform.PhaseOutput
}

type InputTransform interface {
    Transform
    TransformInput(ctx context.Context, req *provider.CompletionRequest) error
}

type OutputTransform interface {
    Transform
    TransformOutput(ctx context.Context, req *provider.CompletionRequest, resp *provider.CompletionResponse) error
}

type StreamingOutputTransform interface {
    OutputTransform
    TransformChunk(ctx context.Context, req *provider.CompletionRequest, chunk *provider.StreamChunk) (*provider.StreamChunk, error)
    TransformAccumulated(ctx context.Context, req *provider.CompletionRequest, resp *provider.CompletionResponse) error
}
```

`Register` sorts each transform by the interfaces it implements. Output transforms run on complete responses. On a stream, only a `StreamingOutputTransform` runs: `TransformChunk` sees every chunk (return nil to drop it) and `TransformAccumulated` sees the merged response at the end.

## Built-in Transforms

### System Prompt

```go
sp := transform.NewSystemPrompt("You are a helpful assistant.").
    WithTenantPrompt(tenantID, "You are the support agent for Acme Corp.")
registry.Register(sp)
```

Puts a system message at the front of every request. A tenant with its own prompt (keyed by tenant ID) gets that instead of the global one. Set the `Append` field to true to add the message at the end instead.

### RAG Context

```go
registry.Register(transform.NewRAG(retriever).WithMaxResults(3))
```

`retriever` implements `transform.RAGProvider`:

```go
type RAGProvider interface {
    Retrieve(ctx context.Context, query string, maxResults int) ([]RAGChunk, error)
}
```

The query is the last user message. The chunks go into one system message, placed after any existing system messages, using a default template you can replace with `WithTemplate` (one `%s` for the context). It asks for 5 results unless you change it. A retrieval error is ignored and the request goes on without context.

### Anonymizer

```go
anon := transform.NewAnonymizer()
anon.AddPattern("employee_id", `EMP-\d{6}`, "[EMPLOYEE_ID]")
registry.Register(anon)
```

Replaces email addresses, phone numbers, social security numbers, card numbers and IPv4 addresses in string message content before the provider sees it. `transform.NewAnonymizerOutput()` is the output-phase version: it applies the same patterns to the content of each response choice, and takes `AddPattern` too.

### Normalizer

```go
registry.Register(transform.NewNormalizer())
```

An output transform that trims whitespace from response content and maps provider finish reasons to the standard ones. The `TrimWhitespace` and `NormalizeFinishReason` fields turn each part on or off. `StripProviderMeta` exists but does nothing yet.
