## Implement the Interface

A plugin implements `plugin.Extension` (the `Name()` method) plus whichever hook interfaces it wants:

```go
package myplugin

import (
    "context"
    "log"
    "time"

    "github.com/xraph/nexus/id"
    "github.com/xraph/nexus/plugin"
    "github.com/xraph/nexus/provider"
)

type LogPlugin struct{}

func (p *LogPlugin) Name() string { return "log_plugin" }

func (p *LogPlugin) OnKeyCreated(ctx context.Context, keyID id.KeyID, tenantID id.TenantID) error {
    log.Printf("key %s created for tenant %s", keyID, tenantID)
    return nil
}

func (p *LogPlugin) OnStreamCompleted(ctx context.Context, requestID id.RequestID, model, providerName string, elapsed time.Duration, final *provider.CompletionResponse) error {
    log.Printf("stream %s: provider=%s model=%s tokens=%d elapsed=%s",
        requestID, providerName, model, final.Usage.TotalTokens, elapsed)
    return nil
}

// Compile-time checks
var (
    _ plugin.Extension       = (*LogPlugin)(nil)
    _ plugin.KeyCreated      = (*LogPlugin)(nil)
    _ plugin.StreamCompleted = (*LogPlugin)(nil)
)
```

## Register

```go
gw := nexus.New(
    nexus.WithExtension(&myplugin.LogPlugin{}),
)
```

In a Forge app, pass it through the extension: `nexusext.WithGatewayOption(nexus.WithExtension(&myplugin.LogPlugin{}))`.

## Error Handling

A hook's error never reaches the request. Hooks run synchronously in the request path, though, so a slow hook slows the request (and a per-chunk hook slows the stream). Keep them quick, and move slow work to a goroutine or a queue. The gateway's registry logs hook errors to a no-op logger, so if you care about a failure, log it inside the hook.

## Available Hooks

The `plugin` package has 19 hook interfaces. These fire today: `TenantCreated`, `TenantDisabled`, `KeyCreated`, `KeyRevoked`, `BudgetWarning`, `BudgetExceeded`, `StreamStarted`, `ChunkReceived`, `StreamCompleted` and `StreamFailed`.

These exist but nothing calls them yet: `RequestReceived`, `RequestCompleted`, `RequestFailed`, `RequestCached`, `ProviderFailed`, `CircuitOpened`, `FallbackTriggered`, `GuardrailBlocked` and `GuardrailRedacted`. A plugin that implements them compiles and registers, but those methods won't run. See [Plugins](/docs/infrastructure/plugins).
