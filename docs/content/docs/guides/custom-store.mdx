## Store Interface

`store.Store` composes the persistence interfaces of the tenant, key and usage packages:

```go
type Store interface {
    Tenants() tenant.Store
    Keys() key.Store
    Usage() usage.Store

    Migrate() error
    Close() error
}
```

Pass yours with `nexus.WithDatabase(s)`. The gateway builds its tenant, key and usage services on top, and `gw.Shutdown` calls `Close`. It doesn't call `Migrate` for you (the Forge extension does, on start), so call it once at startup.

## The sub-stores

Each package defines its own `Store`. These are the method sets you implement:

```go
// tenant.Store
type Store interface {
    Insert(ctx context.Context, t *Tenant) error
    FindByID(ctx context.Context, id string) (*Tenant, error)
    FindBySlug(ctx context.Context, slug string) (*Tenant, error)
    Update(ctx context.Context, t *Tenant) error
    Delete(ctx context.Context, id string) error
    List(ctx context.Context, opts *ListOptions) (*ListResult, error)
}

// key.Store
type Store interface {
    Insert(ctx context.Context, k *APIKey) error
    FindByID(ctx context.Context, id string) (*APIKey, error)
    FindByPrefix(ctx context.Context, prefix string) ([]*APIKey, error)
    TouchLastUsed(ctx context.Context, id string, at time.Time) error
    Update(ctx context.Context, k *APIKey) error
    Delete(ctx context.Context, id string) error
    ListByTenant(ctx context.Context, tenantID string) ([]*APIKey, error)
    // ...plus the paged List and Count the admin API uses; see key/key.go
}

// usage.Store
type Store interface {
    Insert(ctx context.Context, rec *Record) error
    MonthlySpend(ctx context.Context, tenantID string) (money.USD, error)
    DailyRequests(ctx context.Context, tenantID string) (int, error)
    Summary(ctx context.Context, tenantID string, period string) (*Summary, error)
    Series(ctx context.Context, opts *SeriesOptions) ([]SeriesPoint, error)
    Query(ctx context.Context, opts *QueryOptions) (*QueryResult, error)
}
```

The comments on each interface in the source say which errors to return (`tenant.ErrNotFound`, `tenant.ErrDuplicate`, `key.ErrNotFound`, `key.ErrDuplicate`, `usage.ErrInvalidPeriod`) and when. Read them before you start.

## Example: DynamoDB Store

```go
type DynamoStore struct {
    client *dynamodb.Client
    table  string
}

func (s *DynamoStore) Tenants() tenant.Store { return &dynamoTenantStore{s} }
func (s *DynamoStore) Keys() key.Store       { return &dynamoKeyStore{s} }
func (s *DynamoStore) Usage() usage.Store    { return &dynamoUsageStore{s} }
func (s *DynamoStore) Migrate() error        { return s.createTables(context.Background()) }
func (s *DynamoStore) Close() error          { return nil }

var _ store.Store = (*DynamoStore)(nil)
```

## Key and usage store contracts

The gateway's checks rely on a few rules that the Go types do not enforce. A custom store that breaks one still compiles, so check yours against this list. The tests under `store/storetest` check each rule against the built-in stores (`storetest.Each` runs a test body against every built-in backend), and they're a good model for testing yours.

- `key.Store.Insert` refuses a key whose hash is already stored with `key.ErrDuplicate`, and writes nothing.
- `key.Store.FindByPrefix` returns every key with that prefix, in any status, as a slice. Prefixes are not unique, and the key service compares the hash of each one and reports revoked and expired keys itself. Return an empty slice and a nil error when none match.
- `key.Store.TouchLastUsed` writes `LastUsedAt` and nothing else, as a single-column update. A full-row write here can put a key you just revoked back to active.
- `usage.Store.DailyRequests` counts every record since midnight UTC except those with outcome `refused`. If it counts refusals, a tenant held at its RPM burns its daily quota on them.
- `usage.Store.Summary` accepts `day`, `week` and `month`, and returns `usage.ErrInvalidPeriod` for anything else.
- A tenant id of `""` passed to `DailyRequests`, `MonthlySpend`, `Summary`, `Series` or `Query` means every tenant, including requests attributed to none.

## Built-in Stores

| Store | Constructor | Use Case |
|-------|-------------|----------|
| Memory | `store.NewMemory()` | Development, testing; the default when you pass no store |
| SQLite | `sqlite.New(db *grove.DB)` from `store/sqlite` | Single-node production |
| PostgreSQL | `postgres.New(db *grove.DB)` from `store/postgres` | Multi-replica production |
| MongoDB | `mongo.New(db *grove.DB)` from `store/mongo` | Multi-replica production |
