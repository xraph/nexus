## Installation

You need Go 1.26 or later. Each provider is its own Go module, so you add the root and the providers you call:

```bash
go get github.com/xraph/nexus@latest
go get github.com/xraph/nexus/providers/openai@latest
```

## Create a Gateway

```go
package main

import (
    "context"
    "fmt"
    "log"
    "os"

    "github.com/xraph/nexus"
    "github.com/xraph/nexus/provider"
    "github.com/xraph/nexus/providers/openai"
)

func main() {
    ctx := context.Background()

    gw := nexus.New(
        nexus.WithProvider(openai.New(os.Getenv("OPENAI_API_KEY"))),
    )

    // Initialize fills in the defaults and builds the pipeline.
    if err := gw.Initialize(ctx); err != nil {
        log.Fatal(err)
    }
    defer gw.Shutdown(ctx)

    // The engine sends requests through the pipeline without HTTP.
    resp, err := gw.Engine().Complete(ctx, &provider.CompletionRequest{
        Model: "gpt-4o-mini",
        Messages: []provider.Message{
            {Role: "user", Content: "Hello, what is Go?"},
        },
    })
    if err != nil {
        log.Fatal(err)
    }

    fmt.Println(resp.Choices[0].Message.Content)
}
```

You didn't pass a store, so tenants, keys and usage live in memory and are gone when the process exits. See [PostgreSQL](/docs/stores/postgres), [SQLite](/docs/stores/sqlite) or [MongoDB](/docs/stores/mongo) when you want to keep them.

## Add More Providers

```go
import (
    "github.com/xraph/nexus/providers/anthropic"
    "github.com/xraph/nexus/providers/openai"
)

gw := nexus.New(
    nexus.WithProvider(openai.New(os.Getenv("OPENAI_API_KEY"))),
    nexus.WithProvider(anthropic.New(os.Getenv("ANTHROPIC_API_KEY"))),
)
```

With the default priority strategy every request goes to the first provider you registered. The router doesn't pick a provider by model yet, so read [Routing](/docs/core/routing) before you register a second one.

## Run as an OpenAI-Compatible Proxy

The proxy wants a gateway key on every `/v1` request, so make a tenant and a key first:

```go
import (
    "net/http"
    "time"

    "github.com/xraph/nexus/key"
    "github.com/xraph/nexus/proxy"
    "github.com/xraph/nexus/tenant"
)

t, err := gw.Tenants().Create(ctx, &tenant.CreateInput{Name: "Demo", Slug: "demo"})
if err != nil {
    log.Fatal(err)
}
_, raw, err := gw.Keys().Create(ctx, &key.CreateInput{TenantID: t.ID.String(), Name: "demo"})
if err != nil {
    log.Fatal(err)
}
// The raw key exists only here. Only its hash is stored. Printing it is fine
// for a demo; in a real service, hand it to its owner and never log it.
fmt.Println("gateway key:", raw)

srv := &http.Server{
    Addr:              ":8080",
    Handler:           proxy.New(gw.Engine()),
    ReadHeaderTimeout: 10 * time.Second,
}
log.Fatal(srv.ListenAndServe())
```

A key created without scopes gets `completions`, `embeddings` and `models`. Any OpenAI SDK can now connect to `http://localhost:8080/v1`, with the `nxs_` key as its API key:

```python
from openai import OpenAI
client = OpenAI(base_url="http://localhost:8080/v1", api_key="nxs_...")
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello!"}],
)
```

A request with no key, or any key but a gateway key, gets a 401. See [Authentication](/docs/api-reference/http-api#authentication). For local work you can open the `/v1` routes with `nexus.WithRequireAPIKey(false)`.

## Add Guardrails

```go
import (
    "github.com/xraph/nexus/guard"
    "github.com/xraph/nexus/guard/guards"
)

gw := nexus.New(
    nexus.WithProvider(openai.New(os.Getenv("OPENAI_API_KEY"))),
    nexus.WithGuard(guards.NewPII(guard.ActionRedact)),
    nexus.WithGuard(guards.NewInjection()),
)
```

## Enable Caching

```go
import "github.com/xraph/nexus/cache/stores"

gw := nexus.New(
    nexus.WithProvider(openai.New(os.Getenv("OPENAI_API_KEY"))),
    nexus.WithCache(stores.NewMemory(stores.WithMaxSize(1000))),
)
```
