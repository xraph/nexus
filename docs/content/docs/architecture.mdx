## Overview

Nexus is organized as a set of composable Go packages. The `Gateway` is the root struct that wires everything together.

```
┌─────────────────────────────────────────────────┐
│                    Gateway                       │
│                                                  │
│  ┌──────────┐  ┌──────────┐  ┌──────────────┐  │
│  │ Providers │  │  Router  │  │   Pipeline   │  │
│  │ Registry  │  │ Strategy │  │  Middleware   │  │
│  └──────────┘  └──────────┘  └──────────────┘  │
│                                                  │
│  ┌──────────┐  ┌──────────┐  ┌──────────────┐  │
│  │  Cache   │  │  Guards  │  │  Transforms  │  │
│  │ Service  │  │ Service  │  │   Registry   │  │
│  └──────────┘  └──────────┘  └──────────────┘  │
│                                                  │
│  ┌──────────┐  ┌──────────┐  ┌──────────────┐  │
│  │  Store   │  │  Plugin  │  │    Model     │  │
│  │  Layer   │  │ Registry │  │   Aliases    │  │
│  └──────────┘  └──────────┘  └──────────────┘  │
└─────────────────────────────────────────────────┘
```

## Request Flow

Every request flows through the pipeline middleware chain, sorted by priority:

1. Request ID (5): assign the request id
2. Tracing (10): a span per request, only with `WithTracer`
3. Usage (15): record, price and attribute every request, unless usage is off
4. Timeout (20): the request deadline, when the timeout is above zero (30s by default)
5. Identity (30): tenant and key ids, so the cache and usage agree on who asked
6. Access (40): the tenant must be active and the key must hold the scope the route needs
7. Quota (50): token cap, daily requests, monthly budget, RPM and TPM, and the gateway-wide rate limit
8. Stream Lifecycle (60): extension hooks for streams, and the tenant's stream duration and token caps
9. Guardrails (150): input checks before the call, output checks on a complete response, only with `WithGuard`
10. Transforms (200): input and output transforms, only with `WithTransforms`
11. Alias Resolution (250): rewrite a virtual model name to a concrete model, only with `WithAlias`
12. Model Policy (260): the tenant's allowed and blocked models
13. Cache (280): serve or store a cached response, only with a cache configured
14. Retry (340): retry a failed provider call with backoff, when retries are above zero (2 by default)
15. Custom middleware: yours, sorted into this list by its own priority
16. Provider Call (350): pick a provider with the routing strategy and call it. Always last.

The usage stage sits above everything that can refuse, replay or retry a request, so one request produces one usage record whatever happens below it. That includes a request the access or quota stage refuses, which is recorded as `refused` at $0.

The HTTP edge runs before this chain. It reads the gateway key, checks it, and puts the tenant, the key id and the key's scopes into the context, so the pipeline starts with an identity it can trust. A request with no valid key never reaches the chain, which is why those 401s are not in the usage store. See [Errors](/docs/concepts/errors).

## Pipeline Middleware

All middleware implements:

```go
type Middleware interface {
    Name() string
    Priority() int
    Process(ctx context.Context, req *Request, next NextFunc) (*Response, error)
}
```

Lower priority numbers run first and sit further out, wrapping everything after them. Add your own with `nexus.WithMiddleware(m)`. A stage with a priority below 340 runs once per request. One above 340 runs inside the retry loop, so once per attempt. `gw.PipelineStages()` lists the stages a gateway ended up with.

## Plugin System

Plugins implement lifecycle hooks as separate interfaces. The registry checks each plugin against every hook interface once, when you register it, so an event only reaches the plugins that implement it:

```go
type Extension interface {
    Name() string
}

// Opt in to specific events
type KeyCreated interface {
    OnKeyCreated(ctx context.Context, keyID id.KeyID, tenantID id.TenantID) error
}
```

19 hook interfaces cover requests, streams, provider events, guardrails, tenants and keys, and budgets. The gateway fires 10 of them today: tenant, key, budget and stream events. See [Plugins](/docs/infrastructure/plugins).
